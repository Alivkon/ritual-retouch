# 003. В списке одноразовой почты оставлены только домены .ru

Дата изменения: 18 октября 2026 года, Europe/Belgrade.
Запись восстановлена по выполненной работе в текущей переписке.

## Цель и изменения

- По запросу пользователя список `src/data/disposable-email-domains.json`
  отфильтрован по окончанию `.ru`: вместо 9 902 доменов осталось 175,
  включая `mailgu.ru`. Домены других зон удалены.
- В `tests/emailRegistration.test.cjs` обновлены ожидания: все записи списка
  оканчиваются на `.ru`, а `yopmail.com` и `maxxspace.com` исключены из блокировки.
- Обновлены `README.md` и `docs/disposable-email-research.md`.
- Текст сообщения об отказе сохранён.

## Проверки и применение

`yarn build`, три теста регистрации и `git diff --check` прошли.
Приложение пересобрано и перезапущено через Docker Compose.
В работающем контейнере проверены 175 доменов зоны `.ru`, исключение других зон
и ответ HTTP 400 с выбранным сообщением для регистрации с `mailgu.ru`.
