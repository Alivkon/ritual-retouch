# Перенос приложения в apps

## Цель

Перенести интернет-приложение `ritual-retouch` из `/opt/bots` в `/opt/apps`, не
нарушив его работу и сохранив проектные данные.

## Изменения

- Весь каталог проекта перемещён в `/opt/apps/ritual-retouch`, включая `.env`,
  Git-репозиторий, зависимости, собранный frontend и локальные данные.
- В README инструкции запуска обновлены на новый путь.
- Конфигурация Docker Compose и Traefik не менялась: имена сервисов, сеть,
  тома и доменный маршрут сохранены.

## Затронутые файлы

- `README.md`
- Каталог проекта перемещён из `/opt/bots/ritual-retouch` в
  `/opt/apps/ritual-retouch`.

## Проверки

- `docker compose config -q` из нового расположения завершился успешно.
- `docker compose ps` показывает оба сервиса работающими: приложение и
  PostgreSQL находятся в состоянии `Up`.
- Старый каталог отсутствует; рабочее дерево Git и незакоммиченные изменения
  сохранены.

## Применение

Контейнеры не перезапускались и не пересоздавались; сайт продолжил работать
без перерыва. Существующая Docker-метка `project.working_dir` пока содержит
прежний путь и обновится при последующем пересоздании контейнера; на работу
сайта и запуск Compose из нового каталога это не влияет.
