# 007. Проверка почты при вводе с сообщением под паролем

Дата изменения: 18 октября 2026 года, Europe/Belgrade.

## Цель и изменения

По уточнению пользователя удалены всплывающие уведомления об ограничениях
регистрации. Проверка выполняется во время ввода email, сообщение показывается
только текстом в существующем блоке под полем пароля.

- Добавлена проверка формы по единому списку
  `src/data/disposable-email-domains.json`, который используется сервером.
  Отдельная копия списка и запросы к серверу при каждом вводе не создаются.
- Проверяются полные адреса, регистр, Unicode-домены, домен и его поддомены.
- Для адреса вне `.ru` показывается ранее выбранное сообщение о зоне `.ru`.
- Для одноразового домена `.ru` показывается ранее выбранное сообщение
  о сервисе временной почты.
- Сообщение обновляется при вводе и при переходе на вкладку регистрации,
  скрывается после исправления адреса на разрешённый.
- Перед отправкой формы выполняется повторная проверка. Адреса с ограничениями
  не отправляются на регистрацию.
- Удалены HTML и обработчики модального окна ограничений, в том числе показ окна
  при получении серверной ошибки. Ошибки сервера остаются текстом в форме.
- В Docker-сборку фронтенда добавлен исходный JSON-список доменов.
- Проверки при входе и серверная защита регистрации сохранены.

## Затронутые файлы

- `frontend/src/utils/registrationEmail.ts` — проверка введённой почты.
- `frontend/src/main.ts` — обработка ввода и отправки без модальных окон.
- `frontend/index.html` — удалено окно ограничения регистрации.
- `Dockerfile` — подключение общего списка при сборке фронтенда.
- `frontend-dist/index.html` и JavaScript-файл в `frontend-dist/assets/`.
- `docs/disposable-email-research.md` — актуализировано описание поведения.
- Этот отчёт.
