# 005. Сообщение при регистрации с почтой вне зоны .ru

Дата изменения: 18 октября 2026 года, Europe/Belgrade.

## Цель

При вводе почты вне зоны `.ru` во время регистрации показывать сообщение,
указанное пользователем:

> Это российский сервис — Вы можете использовать только почту из зоны «.ru» (КоАП РФ ст. 13,55)

## Изменения

- В форме регистрации сообщение появляется при вводе полного email другой зоны
  и при переключении на регистрацию, если такой адрес уже введён.
- При исправлении адреса на `.ru` сообщение в форме скрывается.
- Кнопка регистрации больше не отключается из-за зоны домена: при отправке
  формы с адресом вне `.ru` открывается окно с точным указанным сообщением.
  Запрос регистрации в этом случае не отправляется.
- В `POST /api/auth/register` добавлена серверная проверка `.ru`: адреса других
  зон отклоняются с HTTP 400 и этим же сообщением до обращения к БД,
  хеширования пароля и отправки письма.
- Для одноразовых доменов `.ru` сохранены отдельная блокировка и прежнее сообщение.
- Актуализированы существующие тесты регистрации, справочная документация
  и файлы сборки фронтенда. Правила входа в аккаунт не изменялись.
