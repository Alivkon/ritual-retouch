# 001. Блокировка регистрации с одноразовой почтой

Дата изменения: 18 октября 2026 года, Europe/Belgrade.
Запись восстановлена по выполненной работе в текущей переписке.

## Цель и изменения

- Исследованы сервисы временной почты, ссылки и результаты сохранены в
  `docs/disposable-email-research.md`.
- Создан `src/data/disposable-email-domains.json`: первоначально 9 902 домена
  из публичной базы с отдельным дополнением `mailgu.ru`.
- Добавлена проверка доменов и их поддоменов с нормализацией регистра и Unicode
  в `src/utils/disposableEmail.ts`.
- В `src/web/auth.ts` регистрация с доменов из списка отклоняется с HTTP 400
  до обращения к БД и отправки письма. Усилена проверка формата email.
- Установлено, что ограничение `.ru` действует только в браузерной форме;
  серверную проверку зоны в рамках этой задачи не добавляли.

## Затронутые файлы

`src/web/auth.ts`, `src/utils/disposableEmail.ts`,
`src/data/disposable-email-domains.json`, `tests/emailRegistration.test.cjs`,
`docs/disposable-email-research.md`, `docs/disposable-email-domains.LICENSE`, `README.md`.

## Проверки и применение

`yarn build`, три теста регистрации и `git diff --check` прошли.
Список проверен внутри Docker-образа. Контейнер приложения пересобран и перезапущен.
Работающий API вернул HTTP 400 для `mailgu.ru`, его поддомена и `yopmail.com`;
главная страница вернула HTTP 200.

Последующие изменения сообщения и состава списка описаны в записях 002 и 003.
