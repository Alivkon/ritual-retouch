# 008. Переход на регистрацию по иконке пользователя

Дата изменения: 18 октября 2026 года, Europe/Belgrade.

## Цель и изменения

По запросу пользователя кнопка с иконкой человека в правом верхнем углу
главной страницы используется для перехода к регистрации.

- Вместо подтверждения «Выйти из аккаунта пользователь?» сразу открывается
  существующая страница авторизации с активной вкладкой «Регистрация».
- Удалены вызов подтверждения выхода и запрос выхода из обработчика кнопки.
  Текущая сессия при переходе сохраняется.
- Такое же действие установлено для иконки в мобильной навигации.
- Подсказки и доступные подписи кнопок обновлены на «Регистрация»;
  мобильная кнопка также подписана «Регистрация».
- При прямом переходе сбрасывается отложенное действие предыдущей попытки
  авторизации, чтобы оно не выполнялось после входа из формы регистрации.
- Удалён неиспользуемый импорт функции выхода из основного файла фронтенда.

## Затронутые файлы

- `frontend/src/main.ts` — действие иконок и подсказка кнопки.
- `frontend/index.html` — подписи настольной и мобильной кнопок.
- `frontend-dist/index.html` и JavaScript-файл в `frontend-dist/assets/`.
- Этот отчёт.

## Проверки и применение

- `yarn build:frontend` — успешно.
- На функциях интерфейса с имитацией DOM проверены обе кнопки для гостя
  и пользователя с активной сессией: открывается вкладка регистрации,
  подтверждение и выход не вызываются, текущий пользователь сохраняется.
- `git diff --check` — без ошибок.
- Docker-образ пересобран, приложение перезапущено.
- На работающем сайте проверены HTTP 200 главной страницы и новой
  JavaScript-сборки, подписи «Регистрация» и отсутствие текста подтверждения выхода.
