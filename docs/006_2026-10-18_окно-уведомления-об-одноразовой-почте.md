# 006. Уведомление об одноразовой почте в общем окне ограничений

Дата изменения: 18 октября 2026 года, Europe/Belgrade.

## Цель и изменения

Предупреждение об одноразовой почте приведено к тому же формату, что и
предупреждение о регистрации с адресом вне `.ru`.

- При отказе сервера из-за одноразовой почты открывается модальное окно
  «Ограничение регистрации» с выбранным ранее текстом:

  > Этот домен относится к сервису временной почты. Для регистрации используйте постоянный почтовый ящик.

- Оба предупреждения используют существующее окно, оформление, затемнение фона
  и закрытие крестиком или нажатием на фон.
- При каждом открытии текст окна обновляется в соответствии с причиной отказа.
- Сообщение об одноразовой почте также остаётся в форме регистрации.
- Серверная блокировка и список 175 доменов `.ru` не изменялись.

## Затронутые файлы

- `frontend/src/main.ts` — общее открытие и закрытие окна ограничений,
  вызов при получении ошибки об одноразовой почте.
- `frontend/index.html` — комментарий общего окна ограничений регистрации.
- `frontend-dist/index.html` и собранный JavaScript в `frontend-dist/assets/`.
- `docs/disposable-email-research.md` — описание нового способа уведомления.
- Этот отчёт.

## Проверки и применение

- `yarn build:frontend` — успешно.
- Проверка функций формы с имитацией DOM — успешно: отказ из-за одноразовой
  почты открывает окно с правильным текстом, текст меняется между причинами,
  закрытие работает, при входе предупреждение о регистрации не открывается.
- `git diff --check` — без ошибок.
- Образ пересобран и приложение перезапущено через Docker Compose.
- На работающем сервисе проверен HTTP 400 с прежним текстом для `mailgu.ru`,
  HTTP 200 главной страницы и нового JavaScript-файла с сообщением об одноразовой почте.
