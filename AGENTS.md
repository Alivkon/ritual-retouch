# Документирование изменений

После каждой выполненной задачи, изменяющей проект, сохраняйте отдельный отчёт
на русском языке в папке `docs/`. Правило распространяется на изменения кода,
конфигурации, инфраструктуры, тестов и документации.

- Формат имени: `NNN_ГГГГ-ММ-ДД_краткое-название.md`, например
  `005_2026-10-18_обновление-регистрации.md`.
- Номер — следующий после наибольшего номера отчёта в `docs/`, общий для всего
  проекта; при смене даты нумерация не сбрасывается. Используйте минимум три цифры.
- Дату изменения указывайте по часовому поясу `Europe/Belgrade`.
- В отчёте укажите цель, внесённые изменения, затронутые файлы, выполненные
  проверки и их результаты, а также факт применения или перезапуска, если он был.
- Один отчёт описывает одну завершённую задачу и все правки в её рамках.
  Для последующей задачи создавайте новый файл, сохраняя предыдущие записи.
- Описывайте только фактически выполненную работу. Само создание отчёта включайте
  в отчёт по текущей задаче; отдельная запись для этого не нужна.
